# Verbos

## Pronombres enclíticos

Los pronombres son enclíticos cuando se unen al final del verbo. Esto ocurre con:

* el infinitivo,
* el gerundio
* el imperativo afirmativo (pero no imperativo negativo)

Forma:

> verbo + (indirecto) + (directo)

Ejemplo:

> (tú) Pídesela = Pide + se + la

* se → pronombre indirecto ("a él", "a ella", "a usted"). No distingue género ni número.
* la → pronombre directo (la cosa que se pide). Concuerda en género y número.

Cuando aparecen juntos un pronombre indirecto (le o les) y uno directo (lo, la, los, las), le y les cambian a se. Nunca se dice pídelela.

Se puede añadir el complemento indirecto para aclarar o enfatizar el referente del pronombre indirecto. Por ejemplo:

> Pídesela a ella.

## Pronombres proclíticos

En las demás formas verbales, los pronombres son proclíticos: aparecen antes del verbo.

Forma:

> (indirecto) + (directo) + verbo

Ejemplo:

* Se lo doy
* (tú) no se la pidas.
